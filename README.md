# 3분 인스턴트 타로

1909년 원본 도상과 고전적 해석을 바탕으로 한 정적 타로 리딩 사이트.
빌드 과정이 없고 외부 의존성이 하나도 없다. Render 무료 **정적 사이트** 플랜에 그대로 올라간다.

## 왜 정적 사이트인가

셔플, 랜덤 뽑기, 숫자 지정 뽑기, 스프레드 배치, 자리별 해석은 모두 브라우저에서 처리된다.
서버가 필요한 기능이 없으므로 Render의 정적 사이트로 배포하면 무료 웹 서비스의 제약을 전부 피한다.

| | 무료 정적 사이트 | 무료 웹 서비스 |
|---|---|---|
| 유휴 시 잠듦 | 없음 | 15분 후 잠들고 깨는 데 30~60초 |
| 인스턴스 시간 제한 | 없음 | 월 750시간 |
| `robots.txt` 문제 | 없음 | 잠든 동안 크롤러에 `Disallow: /` 응답 |

## 배포

```bash
# 1. 카드 이미지를 한 번 내려받는다 (선택이지만 권장)
bash tools/fetch-cards.sh 800                                    # 맥 · 리눅스 · Git Bash
powershell -ExecutionPolicy Bypass -File tools\fetch-cards.ps1   # Windows PowerShell

# 2. 저장소에 올린다
git init && git add -A && git commit -m "타로 사이트"
git branch -M main
git remote add origin https://github.com/<사용자>/<저장소>.git
git push -u origin main
```

Render 대시보드에서 **New + → Blueprint** 로 저장소를 선택하면 `render.yaml` 설정대로 생성된다.
Blueprint 없이 수동으로 만들 경우 **New + → Static Site** 에서 다음과 같이 넣는다.

- Build Command: 비워 둠
- Publish Directory: `.`

### 이미지를 내려받지 않아도 되는가

된다. 이미지 로딩은 3단 폴백이다.

1. `assets/cards/<파일명>.jpg` (로컬)
2. 위키미디어 공용 `Special:FilePath` (원격)
3. 코드로 그리는 기하 심볼 SVG

다만 배포 사이트가 매 방문자마다 위키미디어에 요청하는 것은 바람직하지 않으므로,
`tools/fetch-cards.sh`를 한 번 돌려 `assets/cards/`를 커밋하는 쪽을 권한다.

## 기능

- **카드 그림 2종** — 1909년 원본 퍼블릭 도메인 스캔 / 코드로 그리는 기하 심볼 카드. 상단에서 전환한다.
- **테마 5종** — 미드나이트(어두운 중성 청), 스카이(흰 바탕 + 파랑), 파치먼트(종이), 잉크(어두운 회청), 커스텀.
  카드 그림과 독립적으로 고를 수 있다.
- **커스텀 테마** — 상단 드롭다운 옆의 원형 칩 두 개를 눌러 HEX 피커로 색을 고른다.
  진한 부분(배경·면)과 밝은 부분(글자·강조) 두 색만 고르면 중간 단계값은 `color-mix`로 만들어진다.
  명도 제한은 없다. 대비가 4.5:1 미만이면 칩 옆에 '대비 낮음' 표시가 뜨지만 선택을 막지는 않는다.
- **스프레드** — 8종. 목록 순서와 가름끈(구분선)은 `js/data/spreads.js`의 `SPREAD_MENU`에서 정한다.
  배열에 `'---'`를 넣으면 그 자리에 가름끈이 들어가고, 꺼져 있는 스프레드와 그로 인해 남는 가름끈은 자동으로 빠진다.
- **질문 입력** — 예/아니오로 답할 질문은 권하지 않는다는 안내를 라벨에 두었다.
- **뽑기 2종** — 섞인 덱에서 무작위, 또는 남은 장수 안에서 몇 번째인지 직접 입력.
- **역방향** — 켜고 끌 수 있다. 방향은 *섞는 순간* 결정되므로 뽑기 방식이 결과에 영향을 주지 않는다.
- **카드 도감** — 78장 전체를 이름·핵심어로 검색. 정/역방향 해석을 함께 본다.
- **기록** — 완성된 리딩을 저장한다. 각 항목의 '해석 보기'를 누르면 당시의 해석 전문
  (자리 이름 · 자리 의미 · 정역방향 · 핵심어 · 본문)이 그대로 다시 펼쳐진다.
  저장된 것은 카드 id와 자리 번호뿐이고, 본문은 열 때마다 `readCardEl()`로 다시 만든다.
  현재는 브라우저 저장소, 백엔드 연결 시 서버.
- **복채 내기** — 자리를 전부 공개하면 활성화되고, 한 리딩에 **한 번만** 낼 수 있다.
  누르면 버튼이 비활성화되면서 글자가 '복채를 / 받았습니다'로 바뀌고, 위 안내 줄에
  `js/app.js`의 `TIP_AFTER` 문구가 나온다. 버튼 크기는 `.btn-tip`에 고정해 두어 글자가 바뀌어도 달라지지 않는다.
- **타로 그만 보기** — 버튼 줄 다음 행 오른쪽 끝의 작은 링크. 페이지를 새로고침한다.
- **다른 타로 보기** — 복채 버튼 아래의 작은 글씨. 덱을 다시 섞고 판을 비운다. 질문과 설정은 그대로 둔다.
- 키보드 단축키: `D` 뽑기, `S` 섞기.

## 구조

```
index.html              단일 페이지. TAROT_CONFIG로 백엔드 주소를 지정한다
css/style.css           테마 3종을 CSS 변수로 전환
js/
  data/major.js         메이저 22장
  data/minor.js         마이너 56장 (수트 정의 + 랭크별 해석)
  data/cards.js         78장 통합, 이미지 저작권 정보
  data/spreads.js       스프레드 정의 — 여기만 고치면 스프레드가 늘어난다
  deck.js               셔플·뽑기 엔진 (crypto 기반, 모듈로 편향 제거)
  cardArt.js            SVG 카드 생성 + 스캔 이미지 폴백
  api.js                저장 계층 추상화 (LocalStore ↔ RemoteStore)
  app.js                UI 컨트롤러
tools/fetch-cards.sh    원본 스캔 78장 수집
render.yaml             Render Blueprint
```

## 스프레드 추가하기

`js/data/spreads.js`의 `SPREADS` 배열에 객체 하나를 추가하면 끝이다. UI·뽑기·해석이 전부 자동으로 붙는다.

```js
{
  id: 'my_spread',
  nameKo: '내 스프레드',
  nameEn: 'My Spread',
  desc: '언제 쓰는 스프레드인지 한 줄 설명',
  enabled: true,
  layout: { type: 'row' },          // 'row' | 'grid' | 'free'
  variants: [{
    id: 'default',
    nameKo: '기본',
    positions: [
      { label: '자리 이름', meaning: '이 자리가 무엇을 말하는지' },
      // ...
    ]
  }]
}
```

`layout.type`이 `'free'`면 각 자리에 `x`/`y`(0~100 백분율)와 선택적으로 `rotate`(도)를 준다.
`layout.ratio`로 판의 가로세로 비율을 정할 수 있다. 세로로 긴 배치는 `'1 / 1'`,
가로로 넓은 배치는 `'5 / 4'`나 `'5 / 3.4'`처럼 준다. 생략하면 `'5 / 4'`가 기본이다.
자리가 5개 이상인 free 배치는 카드가 자동으로 작아져 서로 겹치지 않는다.

자리 이름표는 free 배치에서 카드 위에 띄워 그리므로 자리 높이를 차지하지 않는다.
켈틱 크로스의 2번처럼 다른 카드와 같은 지점에 놓이는 자리는 `labelAt: 'bottom'`을 주어
이름표를 카드 아래로 내린다. 그러지 않으면 두 이름표가 같은 자리에 겹쳐 글자가 뭉개진다.

좌표를 새로 잡을 때는 카드끼리, 그리고 **이름표와 이웃 카드가** 겹치기 쉬우므로
브라우저에서 모든 자리를 채워 눈으로 확인하는 편이 좋다.

## 백엔드 확장

`js/api.js`가 저장 계층을 추상화하고 있다. Render에 web service를 올린 뒤
`index.html`의 `TAROT_CONFIG.apiBase`에 주소를 넣으면 `app.js`를 고치지 않고 서버 저장으로 바뀐다.
서버가 자고 있거나 응답하지 않으면 자동으로 브라우저 저장소로 떨어지므로, 무료 플랜의 콜드 스타트에도 화면이 멈추지 않는다.

구현해야 할 엔드포인트:

```
GET    /api/readings        → Reading[]
POST   /api/readings        → Reading
DELETE /api/readings/:id    → 204
GET    /api/settings        → Settings
PUT    /api/settings        → Settings
```

> 무료 Render Postgres는 30일 후 만료된다. 영구 저장이 필요하면 Neon이나 Supabase의
> 무료 Postgres를 쓰고 `DATABASE_URL`만 바꾸면 된다.

## 이미지 저작권

카드 이미지는 **Rider–Waite–Smith Tarot(1909)** 의 원본 스캔이며 퍼블릭 도메인이다.

- 그림: Pamela Colman Smith (1878–1951)
- 미국: 1909년 발행, 저작권 미갱신으로 퍼블릭 도메인
- 영국·EU: 화가 사후 70년이 지난 2022년 1월 1일부터 퍼블릭 도메인
- U.S. Games Systems가 보유한 권리는 박스 디자인과 실물 카드에 한정되며, 덱 안의 원본 이미지에는 미치지 않는다

주의할 점 두 가지.

1. **원본 스캔만 사용한다.** 후대 상업 판본의 재채색 이미지(선명한 하늘색 계열)는 그 회사의 판본이므로 쓰지 않는다. `tools/fetch-cards.sh`는 위키미디어 공용의 1909년 원본만 가져온다.
2. **"Rider-Waite"라는 이름은 상표로 남아 있다.** 사이트 이름이나 브랜딩에는 쓰지 않고, 출처 표기에만 사용한다.

해석 텍스트는 고전 전통에서 널리 쓰이는 표준 의미를 직접 정리해 작성한 것이며, 특정 저작물의 문구를 옮기지 않았다.

법률 자문이 아니므로, 상업적으로 운영할 계획이라면 해당 국가 기준으로 한 번 더 확인하는 편이 좋다.

### 반응형

배치는 **어느 폭에서도 모양을 유지한 채 통째로 축소된다.** 세로로 쌓거나 줄바꿈하지 않는다.
카드가 많은 스프레드를 세로로 늘어놓으면 스크롤이 지나치게 길어지고 배치의 뜻이 사라지기 때문이다.
(참고: 켈틱 크로스를 390px 화면에서 세로로 쌓으면 4,000px이 넘지만, 축소하면 판 높이가 362px이다.)

비결은 **카드 폭을 픽셀이 아니라 판 너비의 비율로 잡는 것**이다.

```css
.layout-free .slot { width: min(17.7%, 200px); }                      /* 4자리 이하 */
.layout-free:has(.slot:nth-child(5)) .slot { width: min(12.4%, 140px); }
.layout-free:has(.slot:nth-child(8)) .slot { width: min(10.4%, 118px); }
```

자리 좌표가 백분율이므로 카드 폭도 백분율로 두면 배치 비율이 그대로 보존된다.
픽셀 상한(`min()`의 두 번째 값)은 넓은 화면에서 카드가 과하게 커지지 않게 하는 용도다.

한 줄 배치(`layout-row`, 원 카드·쓰리 카드)도 같은 원리다. 폭을 고정하면 좁은 화면에서
한 줄에 못 들어가 세로로 줄바꿈되므로, flex로 남은 폭을 나눠 쓰게 한다.

```css
.layout-row .slot { flex: 1 1 0; min-width: 0; max-width: 200px; }
```

쓰리 카드는 320px에서 카드 91px, 1280px에서 200px로 항상 한 줄을 유지한다.

판에 `container-type: inline-size`를 주었으므로 판 너비를 기준으로 컨테이너 쿼리를 쓸 수 있다.
판이 640px보다 좁아지면 자리 이름표를 숨기고 번호 배지(`.slot-no`)로 바꾼다.
전체 이름과 의미는 **카드를 누르면 뜨는 확대 보기**와 아래 해석 목록에서 볼 수 있다.

판 비율(`--board-ratio`)과 카드 회전(`--card-rotate`)은 CSS 변수로 넘긴다.
`style.aspectRatio`처럼 인라인 속성으로 넣으면 CSS가 덮어쓸 수 없다.

python3 -m http.server 8000
